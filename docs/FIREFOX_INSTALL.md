# Firefox installation

## Recommended install

Install the signed release from Firefox Add-ons after the maintainer publishes it:

Firefox Add-ons URL: _to be added after AMO approval_

Firefox requires released extensions to be signed. The ZIP generated by this
repository is intended for AMO submission or temporary development testing, not
for permanent end-user installation.

## Temporary testing

Use this only for development or review:

1. Run `pnpm run build:firefox`.
2. Open `about:debugging` in Firefox.
3. Choose **This Firefox**.
4. Click **Load Temporary Add-on...**.
5. Select `build/firefox-mv3/manifest.json`.

Temporary add-ons are removed when Firefox restarts.

## Updating

After the add-on is published on Firefox Add-ons, Firefox handles normal updates
through AMO.

## Privacy
